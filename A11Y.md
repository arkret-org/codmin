# Codmin accessibility

Codmin uses Glory semantic widgets and Sapid controls. Names, headings, tables,
links, buttons and inputs are mapped to browser accessibility semantics.
Authentication pages expose a main landmark. The application shell provides
responsive navigation and a skip link. Destructive operations require an
explicit confirmation phrase and, where required by the API, a validated audit
reason. In-flight action buttons reject duplicate submissions.

The automated procedure and limits are described in [docs/A11Y.md](docs/A11Y.md).
The Glory migration has its own real browser regression suite. Backend service
and assistive-technology acceptance remain distinct from mocked browser tests.
